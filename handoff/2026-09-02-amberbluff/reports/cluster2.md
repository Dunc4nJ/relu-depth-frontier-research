# Technical audit report: artifacts G-0019 through G-0062 (MAX11 two-hidden-layer campaign)

Workspace: `/data/projects/relu-depth-frontier-research`. Target: exact representation of MAX_11 by a ReLU network with exactly two hidden layers and arbitrary real weights (known for n <= 10 via Rueß et al., arXiv:2607.21651).

**Frame.** The campaign works inside the Rueß et al. ansatz (arXiv:2607.21651 §4.1, `literature/papers/2607.21651.txt` lines 306-400): atoms are Φ_{A,B}(x) = max( Σ_{(i,j)∈A} max(x_i,x_j), Σ_{(i,j)∈B} max(x_i,x_j) ) with A, B multisets of k=5 index pairs (loops (i,i) allowed, meaning x_i), fully symmetrized as F_{A,B} = Σ_{σ∈S_11} Φ_{A,B}(σx). On the sorted cone C = {x_1 ≤ … ≤ x_11} every atom is a linear form plus integer combinations of ReLU(d·x); a certificate is a rational vector λ with all hinge coefficients cancelling (their eq. 2) and the residual linear part equal to x_11 (eq. 3). Everything in G-0019..G-0062 except G-0020/22/31/35/39/43/60 lives inside this finite ansatz.

## 1. Definitions

- **Signed mass / signed core.** Cancel the common edge multiset C = A ∩ B and write A = C + A′, B = C + B′. Pointwise max(S_A,S_B) = S_C + max(S_{A′},S_{B′}) (Lean: `max_add_common` in `formalization/Formalization/Obstruction.lean`). The reduced signed multigraph W = B′ − A′ is the *signed core*; the *signed mass* s ≤ 5 is the number of occurrences on each side. After full symmetrization a common nonloop contributes only 2(n−2)!·F_2 and a common loop only (n−1)!·F_1 (F_m := Σ_{|S|=m} max_{i∈S} x_i), so the atom function depends only on W plus padding counts (G-0027, G-0028). G-0027 census: 754,017 loopless signed orbits. Loop-inclusive G-0037/G-0038 stream: 7,015,841 orbits (mass 0/1/2/3/4/5 = 1/5/107/3,198/134,193/6,878,337).

- **Loop-inclusive signed-W schema** (`artifacts/math/G-0028/LOOP_INCLUSIVE_SIGNED_W_SCHEMA.md`). For an ordering π = (v_0..v_10) the branch word is w_r(π) = W[v_r,v_r] + Σ_{t<r} W[v_r,v_t]; the diagonal term is what the quarantined G-0021 v1 run omitted (planted n=5 witness: direct 216 vs old replay 372). Canonical column: zero common loops, 5−s common nonloops; base_r = a_−·10! + (5−a_−)·2r·9!. Padding choices differ by multiples of (L−E), so the linear span is generated by one column per W-orbit plus the two base atoms 5E and 5L; this compression does NOT preserve a nonnegative cone.

- **Full-support vs proper-support.** Full-support (full-core) means the signed core touches all 11 coordinates (active vertices = 11); proper means fewer. Full-support counts: mass 3: 3; mass 4: 1,465; mass 5: 384,425.

- **Primitive hinge directions / degree universes.** A hinge is ReLU(d·x) with d an integer zero-sum vector, gcd 1, first nonzero entry positive, whose hyperplane meets the interior of C, equivalently the proper prefix sums of d take both signs (if all prefix sums are ≥ 0 the hinge vanishes on C, via d·x = −Σ_j prefix_j(d)(x_{j+1} − x_j), G-0024). The degree-k universe is the lex-sorted set of primitive differences of two distinct weak compositions of k into 11 parts, minus sign-definite ones: |D3| = 10,065, |D4| = 99,858, |D5| = 657,822 (D5 \ D4 = 557,964; G-0044's 657,833 includes 11 linear rows). G-0051's decisive correction: mass-4 atoms emit 89,793 directions outside D3, so the 10,065-row system that is complete for mass ≤ 3 is NOT a complete test for mass 4.

- **Λ, the eleventh alternating finite-difference functional.** On an ordered-chamber linear coefficient vector c: Λ(c) = Σ_{j=1}^{11} (−1)^{11−j} C(10,j−1) c_j = (1,−10,45,−120,210,−252,210,−120,45,−10,1)·c. Equivalent face: for any symmetric f with binary profile G(t) = f(1_{t ones}), Δ^{11} G(0) = Σ_t (−1)^{11−t} C(11,t) G(t) = (−1)^{12} Λ(c) when f is chamber-linear with coefficients c. The ledger's "λ row" on a column is Δ^{11} of that atom's full binary profile (G-0052 checks direct binary profiles against normal-form evaluations), so it is defined even for atoms with hinges; for a hinge-free combination it coincides with Λ of the combined linear part. Λ(MAX11) = 1 (11! under the matrix normalization, where the target is 11!·x_11).

- **U-statistic.** U_h(x) = Σ over injections f:[r]→[N] of h(x_{f(1)},…,x_{f(r)}), the unnormalised injection symmetrization of an r-variable kernel; the symmetrized atom of a proper core is such a U-statistic with r < 11.

- **S0/S1 baselines** (G-0051 staged plan). S0 = the 1,465 full-support mass-4 seeds alone; S1 = S0 plus the exact low-mass core (G-0050's 488-column proper basis + 3 full mass-3 seeds = 491). The span-equivalent S1 baseline used by G-0057/G-0059/G-0061/G-0062: 867 exact S0 basis columns + 491 = 1,358 columns.

- **H8 filtration.** Rows of D4 have support 3..8 (counts 825 / 8,250 / 28,182 / 38,346 / 20,790 / 3,465). H8 is the 3,465-row support-8 block. A column on r active coordinates is exactly zero on rows of support > r; the "proper-vanishing hypothesis" (G-0058) proposed that ALL proper mass-4 columns vanish on H8, which would make H8 restricted to full seeds a decisive filtration.

- **Zero-high** (defined later, in G-0068, outside the assigned range): a genuine mass-5 column whose D5 \ D4 (degree-five-only) hinge fingerprint is empty; 526 of 11,542 registered natural single-edge mass-5 columns are zero-high, all same-family.

## 2. The central obstruction: Λ and full-support cores

**Statement** (`artifacts/cleanroom/G-0047-lift-audit/PROPER_CORE_THEOREM.md`; ledger C-0011). If h has r < N variables, the binary profile of U_h is G_h(t) = Σ_{R⊆[r]} (t)_{|R|} (N−t)_{r−|R|} h(1_R), a polynomial in t of degree ≤ r, so Δ^N G_h(0) = 0; while Δ^N of MAX_N's profile (0,1,…,1) equals (−1)^{N+1} ≠ 0. Common padding contributes only F_1 and F_2. Hence every proper-core symmetrized atom has λ = 0, and any certificate Σ_j c_j F_j = MAX11 within the ansatz needs a column with λ ≠ 0, i.e. a full-support signed core (linear functionals see only the coefficient-weighted sum, so arbitrary real coefficients are covered). This is a correct, elementary theorem over R for the symmetric pair-orbit ansatz. It is NOT a statement about unrestricted networks (first-layer rows that read all coordinates escape it), and it is only necessary: full cores with λ ≠ 0 generally carry non-braid hinges that still have to be cancelled.

**What the Lean file proves.** `formalization/Formalization/InductionObstruction.lean` (statement match in `formalization/INDUCTION_OBSTRUCTION_STATEMENT_MATCH.md`) kernel-checks only the coefficient-space fact: Λ annihilates the ten ordered-chamber vectors of F_1..F_10 (coefficients C(r−1,m−1)), Λ(e_11) = 1, hence e_11 is outside span_R of those ten vectors (axioms propext, Classical.choice, Quot.sound; no sorry). It does not formalize the U-statistic reduction, the graph censuses, or any network statement. The ledger keeps C-0011 at evidence class **ASSERTED** (`CLAIMS_LEDGER.md` line 119) despite the cleanroom audit `g0047_theorem_audit_v1.json` (verdict `CONSISTENT_WITH_WORDING_CAVEAT_AND_STRONGER_PROPER_CORE_THEOREM`). The weaker G-0047 producer theorem (lower-MAX induction plus common padding lands in span(F_1..F_10), which never contains MAX11; `OBSTRUCTION.md`) is fully proved, and G-0047 also shows none of the 12,459 balanced full-tree orbits is braid-linear on its own.

## 6. G-0060 Boolean Möbius and cube universality

Theorem (arbitrary biases, real weights, no symmetry): for N = c + Σ_j a_j φ_j with φ_j = ReLU(β_j + Σ_i b_ji ReLU(γ_i + w_i·x)), a term independent of some coordinate has charge zero, so Σ_j a_j Δ_[n] φ_j = Δ_[n] MAX_n = (−1)^{n+1} forces at least one output-active second neuron with nonzero charge and full coordinate ancestry D_j = [n]; sparse corollary sk ≥ n. A separated-core strengthening gives rank(A) ≥ n−1, but the biased term Φ_n = ReLU(ReLU(Σ_i x_i − (n−2)) − 2 ReLU(x_1)) shows the wiring hypothesis cannot be dropped. Crucially, G-0060's own subset-zeta construction (its eq. 17) exhibits a bias-free two-hidden-layer network of width 2^n − 1 that matches MAX_n on the whole cube {0,1}^n with coefficients c_T = 1/(|T| C(n,|T|)), proving that NO invariant depending only on standard-cube values can obstruct unrestricted-width bias-free networks. Bearing on the unrestricted problem: it is the only result in this range that applies to arbitrary networks, but its conclusion is vacuous once one first-layer row is dense, and it self-limits the entire λ/charge direction as an unrestricted obstruction.
