# G-0115 result — exact MAX8-to-MAX9 lift-span identities

## Bottom line

The complete degree-four signed-`W` class span generated by adding one edge to
each branch of the public degree-three MAX8 certificate contains an exact full
MAX9 identity. A 395-term rational certificate was replayed independently from
its serialized pairs: all 20,685 complete ordered-cone hinge coordinates
cancel and the nine linear coordinates equal `e_9`.

This is a real exact identity and a strong calibration result for the lift
mechanism. It is **not** a MAX11 solution, coefficient-transport theorem,
induction theorem, network lower bound, or novelty claim. MAX9 already has a
public certificate. The unresolved mathematical question is whether the small
395-term support exposes a source-local equivariant rule that can be frozen and
replayed at MAX10-to-MAX11 without refitting.

## Exact results

### 1. Corrected coefficient-frozen residual repair

Keeping the public coefficients fixed on all 328 lift classes whose signed
`W` orbit occurs in the public MAX9 support, 752 additional degree-four lift
classes exactly repair the nine missing public terms in every hinge coordinate
and in the rational alternating linear invariant `Lambda`. The exact values are

```text
Lambda(retained) = 2071/100
Lambda(missing)  = -1971/100
sum              = 1
```

An independent certificate-only verifier replayed 328 fixed terms, 752 repair
terms, and nine missing terms without loading a matrix, solver, or checkpoint.
This stage establishes an exact residual repair, not by itself the full
nine-coordinate linear identity.

### 2. Compiled mixed-degree full MAX9 identity

Adding exact lower-arity MAX1 through MAX8 identities with the solved binomial
coefficients converts the residual repair into a full MAX9 identity. The
compiled certificate has 1,217 terms: 328 fixed lifts, 752 repairs, and 137
lower-arity terms. A separate clean-room verifier replayed all serialized terms
and obtained zero hinge residual and linear vector `e_9`; a coefficient mutation
failed.

### 3. Unrestricted degree-four-only MAX9 identity

The preregistered unrestricted search gave all 22,666 one-edge lift classes
independent rational coefficients and targeted the full 20,694-coordinate
semantic vector, not only hinges plus `Lambda`. It found an exact solution in
the first 1,024-column prefix:

```text
nonzero terms       395
retained classes    328
repair classes       67
hinge residual        0 / 20,685
linear vector         (0,0,0,0,0,0,0,0,1)
max numerator bits   13
max denominator bits 26
```

The independent verifier recomputed all 395 terms with the bound clean-room DP
without loading the 1.8 GB matrices, CEGIS report, modular solver, exact basis,
residual certificate, or mixed-degree identity. It passed, and a one-unit
coefficient mutation was rejected.

## Preserved falsifier

An earlier apparent residual positive used `sum(a * int(b))` and therefore
truncated fractional partial linear sums. It solved the malformed target with
missing `Lambda = -28` and retained `Lambda = 29`, while its true combined
rational `Lambda` was `-729/100`. It is preserved as a negative control rather
than overwritten. No claim relies on it.
