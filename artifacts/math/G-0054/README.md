# G-0054 — exact S0 mass-four full-seed rank gate

This gate tests only the 1,465 full-core signed-mass-4 orbit columns.  It uses
the complete 99,858-direction degree-four semantic universe, then restricts
the rank matrix to the exact union of rows that are nonzero on at least one
selected column.  A second complete semantic pass must reproduce every
column and prove every omitted row is zero on every selected column.

The rank question is

```text
rank([H; lambda]) ?= rank(H) + 1,
```

where `lambda` is the eleventh binary finite-difference row.  Rank gain is
equivalent to a hinge-free modular circuit with nonzero `lambda`.  Full column
rank excludes any rational seed-only circuit, because nonzero rank modulo one
prime lower-bounds rank over `Q`.

Run:

```bash
.venv/bin/python -B artifacts/math/G-0054/s0_union_rank_gate.py --self-test
.venv/bin/python -B artifacts/math/G-0054/s0_union_rank_gate.py --preflight-only
.venv/bin/python -B artifacts/math/G-0054/s0_union_rank_gate.py \
  --workers 8 --minimum-available-gib 12 --sketch-buckets 4096 \
  --output artifacts/math/G-0054/s0_union_rank_gate_v1.json.gz
```

The deterministic CountSketch is used only as an exact rank lower bound.  If
its rank reaches the 1,465-column upper bound, the complete matrix has full
column rank.  Any sketch deficiency triggers direct dense FLINT rank on the
complete exact-union matrix.  Any augmented rank gain triggers null-vector
extraction and replay on all 99,858 rows before the report is written.

Controls include loop-sensitive DP versus direct permutation enumeration,
full-rank and planted-circuit known answers, a zero-`lambda` dependency, a
duplicate-column/`lambda+1` rank-gain mutation, an integer matrix entry `+1`
hash mutation, and a second complete 1,465-column semantic pass.

## Executed result

The frozen run completed with result
`S0_MIXED_MODULAR_OUTCOME_REQUIRES_REVIEW`.  Both primes gave the same ranks:

```text
prime      rank(H)  rank([H; lambda])  nullity(H)
1,000,003       867                 867         598
1,000,033       867                 867         598
```

The first and second complete semantic passes agreed on all 1,465 columns.
Their exact nonzero-row union has 42,457 of the 99,858 degree-four rows and
12,331,131 nonzero entries; every selected column was independently replayed
as zero on all 57,401 omitted rows.  Each modular rank has an explicit
nonzero 867-by-867 minor lower certificate and an explicit replayed
598-vector nullspace upper certificate.

This is two-prime evidence for a seed-only obstruction, not an exact rational
obstruction.  Equality of modular ranks does not by itself prove
`rank_Q([H; lambda]) = rank_Q(H)`: rational rank can exceed modular rank, and
the modular nullspace bases need not lift to `Q`.  The next exact step is to
certify a rational rank-867 column basis and verify that both all 598 remaining
hinge columns and their `lambda` entries are generated by that same basis.

## Claim boundary

A no-circuit result excludes only combinations of these 1,465 full-support
seeds.  It does not include the 132,728 proper-core mass-four columns and is
therefore not a mass-four-wide obstruction.  A modular circuit is not a
rational MAX11 identity until exact-Q lifting, complete integer hinge replay,
linear-part correction, and independent functional verification.

The executed run found neither a modular rank gain nor an exact-Q theorem.
Its justified conclusion is limited to the two stated finite fields until an
independent certificate audit and rational lifting step are complete.
